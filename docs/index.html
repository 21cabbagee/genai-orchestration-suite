    How the squad works

    🛡️ IntakeRedacts PII, summarises, classifies intent with a few-shot PyTorch model, extracts amounts, IDs and urgency.
    🧭 RouterPlans the run and widens retrieval when intent confidence is low.
    🔎 ResearchTF-IDF + PyTorch vector search over policies, boosted by the predicted intent.
    ✍️ AnalystDrafts a cited answer via LangChain (Claude) or an offline extractive backend.
    🧐 CriticScores grounding and coverage. Weak drafts trigger query expansion and a retry.
    📬 ResponderAuto-resolves, drafts for a human, or escalates to the owning queue.
