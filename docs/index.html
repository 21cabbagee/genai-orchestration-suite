Enterprise GenAI & Agentic Process Orchestration Suite

Six cooperating agents take an incoming employee or customer request, redact PII, classify it, answer it from a policy knowledge base with RAG, check their own answer, and decide whether to auto-resolve, draft for a human, or escalate.

    How it works

    IntakePII redaction · summarise · few-shot classify · extract entities · urgency
    →
    Routerplans steps, widens retrieval when intent is uncertain
    →
    Research → Analyst → Criticvector search with intent prior → cited draft (Claude via LangChain, or extractive) → grounding & coverage check; retries with query expansion
    →
    Responderauto-resolve · agent-assist · escalate, routed to the owning queue

    Typed shared state

    Every agent reads and writes one pydantic TaskState and appends to an audit trace, so each decision can be explained after the fact.

    Guardrails first

    PII is stripped before retrieval or any LLM call. The critic rejects answers whose sentences aren't supported by retrieved evidence.

    Model-agnostic

    The analyst uses any LangChain chat model. With no API key it falls back to an extractive backend, so tests and this demo run offline.
